# File Explorer Implementation

## Requirements

Create a file explorer component with tree structure, context menu, and file operations.

### Core Features

1. File Tree Display
   - Show hierarchical file structure
   - Expandable/collapsible folders
   - File/folder icons
   - Selection handling

2. File Operations
   - Create new file/folder
   - Rename items
   - Delete items
   - Move items
   - Context menu support

3. Navigation
   - Keyboard navigation
   - Click handling
   - Double-click to open
   - Right-click for context

### Technical Requirements

1. Tree Structure
   - Recursive component rendering
   - Efficient updates
   - State management
   - Path handling

2. User Interactions
   - Context menu positioning
   - Drag and drop support
   - Selection management
   - Keyboard shortcuts

3. File System Operations
   - Create operations
   - Delete operations
   - Move operations
   - Rename operations

- Test selection handling
