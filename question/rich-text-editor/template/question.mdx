# Rich Text Editor Implementation

## Requirements

Create a rich text editor that supports:

1. Basic text formatting (bold, italic, underline)
2. Headings
3. Links
4. Character count
5. Undo/Redo functionality

### Core Features
- Text formatting toolbar
- Content editable area
- Character counter
- Keyboard shortcuts
- Selection handling

### Technical Requirements
1. Use native browser Selection and Range APIs
2. Implement command pattern for operations
3. Handle keyboard shortcuts (Ctrl/Cmd + B, I, U)
4. Maintain clean HTML output
5. Track text changes and character count

### Testing Requirements
- Test toolbar button functionality
- Test keyboard shortcuts
- Test text formatting
- Test character count accuracy
- Test undo/redo operations

### Bonus Features
- Markdown support
- Copy/Paste handling
- File attachments
