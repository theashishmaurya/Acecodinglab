# Like/Dislike Button Implementation

## Task Description

You are tasked with implementing a like and dislike button functionality for a social media post using React. The buttons should behave as follows:

1. When the like button is clicked:
   - Increment the like count
   - Make the like button active (visually distinct)
   - If the post was previously disliked, decrement the dislike count and deactivate the dislike button

2. When the dislike button is clicked:
   - Increment the dislike count
   - Make the dislike button active (visually distinct)
   - If the post was previously liked, decrement the like count and deactivate the like button

3. When clicking an already active button:
   - Decrement the count for that button
   - Deactivate the button

## Requirements

- Implement the logic in the `App.js` file
- Use the provided CSS classes in the `style.css` file for styling
- Ensure all test cases in the `LikeDislikeButton.test.js` file pass

## Evaluation Criteria

- Correct implementation of the like/dislike functionality
- Proper state management
- Code clarity and organization
- Passing all provided test cases
